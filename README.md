# React + TypeScript + Vite

Vite React TypeScript app in this workspace.

## Prerequisites

Node.js 20.19+ or 24 (this folder has an `.nvmrc` set to 24).

```bash
nvm use
```

## Scripts

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and production build
npm run preview  # serve the production build
npm run lint     # eslint
```

The app is the official Vite `react-ts` starter: a counter on `src/App.tsx` with hot module replacement.
